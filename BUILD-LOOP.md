# Build loop — one run

1. Read CLAUDE.md, SPEC.md, FEEDBACK.md, ROADMAP.md.
2. Handle new FEEDBACK.md notes first (fix, then reply under the note with what changed).
3. Do the top unchecked ROADMAP item. Stay inside it; note follow-ups as new roadmap items instead of doing them.
4. Keep behaviors pure (no three/DOM imports). Keep `npm run validate` and the kitchen-sink scene working; add to the kitchen-sink scene whenever a feature is added.
5. Check the item off, append a line to LOG.md (`date — item — result`), commit and push to main (fetch + rebase first).
6. Report to Colin, phone-readable: what was built, how to try it, what's unverified, what's next.
